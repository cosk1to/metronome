Calage image / son (Bluetooth)

Surtout utile avec un casque ou une enceinte Bluetooth, qui retardent le son. Avec le haut-parleur de l'appareil, laisse 0.
Lance le métronome avec le son : si le point rebondit avant le clic, appuie sur + ; s'il rebondit après, sur −. Mémorisé sur cet appareil : à refaire si tu changes de casque ou d'enceinte.

Suis le bout de la baguette : le temps tombe quand il rebondit. Le chef est vu de face.
